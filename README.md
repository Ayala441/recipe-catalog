# Рецепттер каталогы (Recipe Catalog)

## Жоба туралы
Бұл веб-қосымша пайдаланушыларға түрлі ас үй рецептерін іздеуге, оларды санаттар бойынша сұрыптауға және өз рецептерін жүйеге қосып бөлісуге мүмкіндік береді. Жоба PHP және MySQL көмегімен әзірленеді.

## Негізгі мүмкіндіктер
- Пайдаланушыларды тіркеу және кіру (Authentication)
- Рецепттерді қосу, қарау, өңдеу және жою (CRUD)
- Ингредиенттер мен атаулар бойынша іздеу
- Санаттар бойынша сүзу
- Қауіпсіздік және деректерді валидациялау

## Дерекқор құрылымы (Кестелер)
- **users**: Пайдаланушы мәліметтері (id, username, email, password)
- **categories**: Рецепт санаттары (id, name)
- **recipes**: Рецепттер (id, title, description, ingredients, instructions, category_id, user_id, image)

## Негізгі беттер тізімі
1. `index.php` — Басты бет
2. `catalog.php` — Рецепттер каталогы
3. `recipe_detail.php` — Рецепттің толық сипаттамасы
4. `register.php` / `login.php` — Тіркелу және кіру
5. `add_recipe.php` — Жаңа рецепт қосу
6. `profile.php` — Жеке кабинет

## Технологиялар
- Frontend: HTML5, CSS3, JavaScript
- Backend: PHP
- Database: MySQL
